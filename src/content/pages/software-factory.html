What to give the Factory

Important enough to do, but rarely important enough to interrupt your best engineers: production bugs, flaky tests, code hygiene and small features. The Factory reproduces the failure, writes the fix, adds a regression test and hands the pull request to the engineer who owns the service.

Agents that work on your repository

Conflict Resolver resolves merge conflicts on open pull requests. Janitor and Code Health clears dead code and keeps the repository healthy. Test Triage Agent finds flaky tests, reproduces the failure and proposes a fix.
