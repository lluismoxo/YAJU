FAQ

  • The Yaju CLI brings deployment, inspection and governance of your agents into the terminal. It talks to the same Agent Orchestration System as the dashboard.

  • No. Anything you can do from the Yaju dashboard, you can do from the CLI, including audit trails, credentials and policy.

  • Yes. Running the CLI inside CI/CD pipelines is an explicit use case, and it needs no change to how your pipelines are built.

  • Secrets are never written to your machine. The CLI attaches credentials at runtime from the Yaju vault, so the value never lands in local configuration, in your shell history or in your code.

  • Yes. Agents built outside Yaju reach credentials, cost data and audit trails through the same commands as agents built on it.

  • Yes. Policies are applied from the CLI and enforced by the runtime at the moment the agent acts.

  • No. The CLI is one surface onto the Yaju Agent Orchestration System. The runtime, the vault and the audit trail sit underneath it and are shared with the dashboard and the SDK.
